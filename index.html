Fonctionnalités

Tout ce dont vous avez besoin

Un carnet de recettes complet, sans superflu.

Créer & modifier
Rédigez vos recettes de zéro, étape par étape. Modifiez-les à tout moment, sans connexion.
Catégories
Organisez vos recettes par catégorie (entrées, desserts, plats rapides…). Filtrez en un geste.
Ajuster les portions
Changez le nombre de portions et toutes les quantités se mettent à jour automatiquement. Plus de calcul mental.
Photos
Ajoutez une ou plusieurs photos par recette depuis votre bibliothèque ou directement depuis l'appareil photo.
PDF & impression
Exportez n'importe quelle recette en fichier PDF, ou envoyez-la directement à l'impression depuis l'app.
Partager une recette
Partagez une recette vers une autre application via la feuille de partage standard du système.
Import depuis une URL
Collez un lien depuis Marmiton, 750g, BBC Good Food — la recette s'importe automatiquement via schema.org/Recipe.
Partager depuis le navigateur
Vous repérez une recette en ligne ? Partagez la page depuis votre navigateur vers AvoCook. Import en un geste.
Génération IA
Scannez une recette depuis une photo, ou décrivez un plat pour obtenir une recette complète. Compatible OpenAI.
Optionnel
Liste de courses
Copiez les ingrédients dans le presse-papiers en un geste, ou exportez une liste vers les Rappels iOS.
Minuteurs
Lancez un ou plusieurs minuteurs de cuisson directement depuis une recette. Notification locale même en arrière-plan.
Sauvegarde & restauration
Exportez toutes vos recettes dans un fichier JSON et restaurez-les n'importe quand, sur n'importe quel appareil.
Synchronisation Nextcloud
Connectez votre propre serveur Nextcloud Cookbook pour synchroniser vos recettes entre appareils. Entièrement optionnel.

Fonctionnement

Local d'abord. Nextcloud si vous voulez.

AvoCook est conçu pour fonctionner sans aucun compte. La synchronisation Nextcloud est une option, pas une obligation.

Mode local
Le mode par défaut. Aucun compte, aucune connexion requise. Vos recettes sont stockées dans une base SQLite directement sur votre appareil.
  • Fonctionne en mode avion
  • Données uniquement sur l'appareil
  • Aucun serveur tiers impliqué
  • Sauvegarde manuelle vers un fichier JSON
ou
Synchronisation Nextcloud
Connectez votre propre serveur Nextcloud avec l'application Cookbook. Les données circulent directement entre l'app et votre serveur.
  • Compatible Nextcloud Cookbook
  • Synchronisation multi-appareils
  • Mot de passe d'application, HTTPS obligatoire
  • Aucun serveur tiers — votre Nextcloud uniquement

Le projet

Fait par un étudiant, pour tous les jours

"J'avais mes recettes éparpillées entre des photos, des onglets Safari et des notes. J'ai décidé de construire l'app qui me manquait."

AvoCook a commencé comme un projet perso pendant mes études d'informatique. L'objectif était double : avoir une vraie app de recettes sur mon téléphone, et apprendre à mener un projet React Native de A à Z — de l'écriture du premier composant jusqu'à la publication sur l'App Store.

Au fil du temps, le projet a grandi : modules natifs, synchronisation Nextcloud, import de recettes, génération IA, support multi-plateforme. Chaque fonctionnalité a été l'occasion d'apprendre quelque chose de concret — parfois en se battant deux heures sur un bug qu'on ne comprend finalement pas si mal.

L'app est entièrement open source sous licence GPLv3. Si vous voulez vous en inspirer, contribuer, ou juste regarder comment c'est construit, le code est sur GitHub.

Stack technique

Ce qui tourne sous le capot

Un projet React Native complet, sans raccourcis.

React Native + Expo
Base cross-platform. Expo pour les modules natifs, les assets et le build CI/CD.
TypeScript
Typage complet, du composant à la couche de données. Aucun any implicite.
SQLite
Stockage local des recettes dans une base relationnelle embarquée via expo-sqlite.
i18next
Internationalisation complète en 5 langues avec détection automatique de la locale.
Expo SecureStore
Identifiants Nextcloud stockés dans l'enclave sécurisée du système (Keychain iOS / Keystore Android).
Expo Calendar
Synchronisation des listes de courses avec les Rappels iOS via l'API native.
schema.org parser
Import de recettes depuis n'importe quel site exposant des données structurées Recipe.
Module natif custom
avocook-timer-notifications — notifications locales pour les minuteurs, même app en arrière-plan.
